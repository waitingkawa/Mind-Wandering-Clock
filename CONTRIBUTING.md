# Contributing

Thanks for taking an interest in Mind-Wandering Clock.

## Before opening a pull request

1. Create a branch from `main`.
2. Keep the change focused on one problem or improvement.
3. Run `npm ci` and `npm run check`.
4. Test the timer in a browser. If the change touches the desktop shell, also run `npm run desktop:start`.
5. Include a screenshot for visible interface changes.

Bug reports are most useful when they include the macOS version, Mac architecture, steps to reproduce the problem, and what happened instead.

Large visual or architectural changes should begin with an issue so the direction can be agreed on before implementation.
