# Mind-Wandering Clock

A gentle break timer with synthesized ambient rain, wind, and binaural tones.
The application is self-contained and does not require a Gemini API key.

## Web development

```bash
npm install
npm run dev
```

## macOS desktop application

Build and open a local desktop app:

```bash
npm run desktop:start
```

Create an unpacked `.app`:

```bash
npm run desktop:pack
```

Create Apple Silicon DMG and ZIP installers:

```bash
npm run desktop:dist
```

Build outputs are written to `release/`.
